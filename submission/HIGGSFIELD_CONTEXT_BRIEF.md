## Storyboard

2. A source with an explicit `shippin.cloud` project signal receives a suggested Shippin placement. Show the reason, not an invented confidence percentage.
3. An ambiguous repository stops in Needs review. The user opens “Give this context a home,” chooses Personal, and notes that it is a learning project.
4. The placement saves in HydraDB. Its badge changes from Suggested placement to Your decision. A Raindrop acceptance message confirms the alignment-review event. Original source content remains in its original database.
5. End on **Your judgment becomes context for the next visit.** Show Personal and Shippin clearly separated while preserving the ability to inspect the source.
